Concept, Mechanics, Execution Trace, and Implementation

01
Section 1.1

What is selection sort?

Selection sort is a simple way to put a list in order, from smallest to biggest. It does this by choosing the smallest item, again and again.

• Before: 64, 25, 12, 22, 11
• After: 11, 12, 22, 25, 64

In a list, it works the same way. The list has two parts:

  • • Sorted part: grows from the left, one item at a time.
  • • Unsorted part: shrinks on the right, until nothing is left.
03
Section 1.2

How it works:

Find the smallest, put it first, repeat—each round locks one more number into its final place.

There are only three steps:

1. Scan – Look through the unsorted part and find the smallest number.

2. Swap – Swap it with the first spot of the unsorted part.

3. Repeat – The sorted part grew by one. Do it again until nothing is left.

04
Section 1.3

What happens (Trace steps):

Start: 64, 25, 12, 22, 11 Nothing sorted yet
Pass 1 = 11, 25, 12, 22, 64
Smallest 11, swap with 64
Pass 2 = 11, 12, 25, 22, 64
Smallest 12, swap with 25
Pass 3 = 11, 12, 22, 25, 64
Smallest 22, swap with 25
Pass 4 = 11, 12, 22, 25, 64
25 in place, no swap needed
Remember: Scan, Swap, and Repeat

Implementation

The Code (Python)

selection_sort.py 
def sort(nums):
    size = len(nums)
    for i in range(size - 1):
        minpos = i
        for j in range(i + 1, size):
            if nums[j] < nums[minpos]:
                minpos = j
        temp = nums[i]
        nums[i] = nums[minpos]
        nums[minpos] = temp
    return nums

my_list = [64, 25, 12, 22, 11]
print(sort(my_list))
Output: [11, 12, 22, 25, 64]

SELECTION SORT

Time Complexity • Basic idea and how the algorithm works

What is Selection Sort?

  • • A sorting algorithm that finds the smallest value.
  • • It moves that value to the front of the unsorted part.
  • • It repeats until the whole array is sorted.
  • • The sorted part grows after each pass.

The Basic Steps

1Scan unsorted
2Find smallest
3Swap to front
4Repeat
[4, 2, 5, 1] → [1, 2, 4, 5]

Mathematical Rationale

Why Time Complexity is O(n²)?

Comparisons in Each Pass

Pass 1n – 1 comparisons
Pass 2n – 2 comparisons
Pass 3n – 3 comparisons
Last pass1 comparison
Total comparisons = n(n – 1) / 2

3. INSERTION SORT ALGORITHM

Concept, Virtual Sections & The 3-Step Iteration Loop

12
Section 3.1

Insertion Sort

Insertion Sort is a simple sorting algorithm that works the way we sort playing cards in our hands, by taking one item at a time and inserting it into its correct position

Two Virtual Sections:

  • • Sorted: starts with the first item on the left.
  • • Unsorted: remains on the right until inserted.

Array: [40, 10, 30, 20]

Pass 1: [10, 40 | 30, 20]

13
Section 3.2

3-Step Iteration Loop

1. Pick: Choose the first value in the unsorted section.

2. Slide: Compare from right to left, shifting each larger sorted value one place right.

3. Insert: Place the chosen value in the open slot, then repeat until sorted.

14
Section 3.3 • Worked Example

Insertion Sort Step by Step

Start: [40 | 10, 30, 20] — 40 starts sorted.

Pass 1: [10, 40 | 30, 20] — Pick 10; shift 40 right.

Pass 2: [10, 30, 40 | 20] — Pick 30; shift 40, insert after 10.

Pass 3: [10, 20, 30, 40 |] — Pick 20; shift 40 and 30 right.

Implementation

Insertion Sort Python

insertion_sort.py 
def insertion_sort(nums):
    for i in range(1, len(nums)):
        key = nums[i]
        j = i - 1
        while j >= 0 and nums[j] > key:
            nums[j + 1] = nums[j]
            j -= 1
        nums[j + 1] = key
    return nums

print(insertion_sort([40, 10, 30, 20]))
Output: [10, 20, 30, 40]

Cases

Time Complexity by Case

BEST
O(n)

Already sorted; 1 pass only.

AVG
O(n²)

Random order; elements shift.

WORST
O(n²)

Reverse order; max shifts.

Why O(n²)? In average and worst cases, comparisons and shifts scale with n × n.
18
Summary

Space Complexity & Conclusion

Space Complexity

In-place, uses fixed extra memory.

O(1)
Advantages

Easy to build; fast on small or nearly sorted lists.

Disadvantage

Slow for large datasets due to O(n²) worst case.

Conclusion: Best for small arrays and streaming real-time inputs.

Self-referential Functions, Base Cases & Problem Decomposition

Section 5.1

Recursion Definition

RECURSION: A function that calls itself to solve a smaller version of the problem until it reaches the end condition.
Example:
def countdown(n):
  if n <= 0:
    print("Done!")
  else:
    print(n)
    countdown(n - 1)

countdown(5)
Output:

1
Done!
21
Section 5.2

Rules of Recursion

1. Base Case

The condition that stops the recursion.

if n <= 0: print("Done!")

2. Recursive Step

The function calling itself with a smaller input.

countdown(n - 1)
WARNING: Without a base case, recursion executes infinitely until stack overflow!
22
Section 5.3

Divide-and-Conquer

Divide-and-conquer: Breaking a big problem into smaller subproblems, solving each independently, and combining solutions.
DIVIDE

Break down the original problem into smaller pieces until no further division is possible.

CONQUER

Solve each subproblem individually (directly if small, or recursively).

6. MERGE SORT ALGORITHM

Principles, Divide-Sort-Merge Flow & Python Implementation

25
Section 6.1

Merge Sort Algorithm

  • Sorts elements in ascending or descending order.
  • Uses the DIVIDE AND CONQUER technique.
  • Divides array recursively, then merges ordered halves.
INVENTOR: John von Neumann (1945)
DIVIDE→SORT→MERGE
26
Section 6.2

How Merge Sort Works

DIVIDE: Split array until each has 1 item.

COMPARE: Compare items from subarrays to determine order.

MERGE: Combine in sorted order until 1 complete array remains.

[8, 3, 6, 2]
↓
[8, 3][6, 2]
↓
[8][3][6][2]
↓
[3, 8][2, 6]
↓
[2, 3, 6, 8]
27
Implementation

Merge Sort Python

mergesort.py 
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    result, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i]); i += 1
        else:
            result.append(right[j]); j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
Output: [2, 3, 6, 8]

Section 7.2

Time Complexity Analysis

Merge Sort: O(n log n)

• O(log n) = Number of Levels

Repeatedly dividing problem size by 2 stops at log₂(n) levels.

• O(n) = Work per Level

Merging all subarrays at any given level requires processing n total items.

8. ALGORITHM COMPARISON

Comparing Selection, Insertion & Merge Sort

32
Section 8.1

Comparing Each Algorithm:

a. Selection Sort: Repeatedly finds the minimum element and places it into the sorted partition.

b. Insertion Sort: Inserts each unsorted element into its suitable place by shifting larger elements.

c. Merge Sort: Divides array into two halves, recursively sorts, then merges the sorted halves.

33
Section 8.2

When to Use?

a. Selection Sort Use when the list is small or writing to memory is expensive.

b. Insertion Sort Use when the data set is nearly sorted or very small.

c. Merge Sort Use when sorting large amounts of data requiring predictable O(n log n) performance.
